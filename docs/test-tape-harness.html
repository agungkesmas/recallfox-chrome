RecallTape v3.14.9 — Test Harness

Halaman ini verifikasi behavior baru RecallTape tanpa perlu install addon. Parser dari lib/tape.js di-inline, UI simulasi pakai textarea + button.

Behavior yang dites:
  • Ketik angka 1300 lalu tekan - → otomatis newline ke -
  • Ketik 500 lalu tekan = → otomatis tampilkan subtotal baris
  • Tekan + di baris kosong → lanjut hitung
  • Printer: hidden iframe + 80mm receipt (test dialog print)
  • Save: kirim SAVE_TAPE_TO_VAULT message ke background

Test Scenarios

Scenario 1: Basic Ketik: 1300 → - → 500 → = → + → 200 → = Expected: 1300 - 500 = + 200 = Grand: 1.000
Scenario 2: Dengan catatan Ketik: 1300 Gaji → - → 500 Makan → = → + → 200 Bonus → = Expected: 1300 Gaji - 500 Makan = + 200 Bonus = Grand: 1.000
Scenario 3: Percent Ketik: 1000 → + → 19% PPN → = Expected: 1000 + 19% PPN = Grand: 1.190
